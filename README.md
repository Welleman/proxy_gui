# 🌐 Network Proxy Lab

Легковесный асинхронный forward-proxy с GUI на Tkinter для анализа, тестирования и обучения работе с сетевым трафиком. Написан исключительно на стандартной библиотеке Python.

## ✨ Возможности
- 🚀 Асинхронное ядро на `asyncio` для работы с множеством одновременных соединений
- 🔒 Полная поддержка HTTPS через туннелирование методом `CONNECT`
- 🖥️ Встроенный GUI с живым цветным логом, кнопками управления и статус-баром
- 🧵 Потокобезопасная архитектура (`asyncio` + `threading` + `queue.Queue`)
- 🛡️ Корректная обработка обрывов соединений (`ConnectionResetError`, `BrokenPipeError`) без падения
- 📦 **Ноль внешних зависимостей** — работает на чистой установке Python 3.7+
- 🔌 Архитектура готова для расширения: MITM, парсинг DoH, правила маршрутизации

## 🛠 Требования
- Python 3.7 или выше
- Windows / macOS / Linux
- `tkinter` (обычно поставляется с Python по умолчанию)
